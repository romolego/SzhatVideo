# СжатьВидео 2.3

Отдельный проект на Python 3.11 / PySide6 и FFmpeg. Все изменения доступны в исходниках; код старого EXE для запуска не требуется.

## Скачать и перенести на ноутбук

[**Скачать СжатьВидео 2.3 для Windows x64 — один EXE**](https://github.com/romolego/SzhatVideo/releases/download/v2.3.0/SzhatVideo-2.3.0-Windows-x64.exe)

[Релиз 2.3 и исходники](https://github.com/romolego/SzhatVideo/releases/tag/v2.3.0)

Скачайте EXE и запустите его на Windows 10/11 x64. Установка Python, FFmpeg и папка `_internal` не нужны. На другом компьютере без NVIDIA выберите «Авто» или «CPU». Настройки хранятся в профиле Windows и не переносятся вместе с EXE. Готовый файл доступен через кнопки «Открыть папку с файлом» и «Открыть сжатое видео» внизу окна.

Релиз содержит ровно ту сборку 2.3, которая проверена на рабочем компьютере; контрольные суммы опубликованы в `SHA256SUMS.txt`. EXE распаковывает библиотеки во временную папку автоматически.

## Запуск

Готовый `СжатьВидео.exe` включает FFmpeg, FFprobe и библиотеки интерфейса. Python устанавливать не нужно. Первый запуск может занять несколько секунд, пока распаковываются встроенные библиотеки.

Выберите или перетащите видео. При стандартных настройках приложение проверяет NVIDIA NVENC, анализирует три фрагмента и ставит ползунок на рекомендованную точку. Нажатие на превью открывает сравнение со шторкой. После проверки нажмите «СЖАТЬ ВИДЕО».

Результат сохраняется рядом с исходником с суффиксом `_сжато`. При совпадении имён добавляется номер. Исходник не изменяется; отмена удаляет только промежуточный файл нового результата.

После успешного сжатия внизу доступны «Открыть папку с файлом» (выделяет результат в Проводнике) и «Открыть сжатое видео». Путь последнего результата запоминается между запусками. Если файл перемещён или удалён, кнопки становятся недоступны.

## Изменения

- Настройки сохраняются автоматически в `%APPDATA%/sjvid2/settings.json`.
- Содержимое прокручивается при недостаточной высоте окна; прогресс и кнопка сжатия закреплены внизу. Ползунок имеет фиксированную высоту и сохраняется при разворачивании окна.
- На шкале отображаются все найденные рекомендации: зелёный максимум качества, синий экран, оранжевый телефон. Иконка или её подпись применяет профиль вместе с разрешением. Совпавшие позиции расположены в разных рядах и доступны отдельно.
- Все закрытые выпадающие списки игнорируют колесо и передают его странице, даже при фокусе на списке. Колесо прокручивает список только после его открытия.
- Ползунок качества и числовые поля также передают колесо странице: случайное наведение или фокус не меняют значения. Перетаскивание ползунка, щелчки, клавиатура и кнопки числовых полей работают обычно.
- Рекомендации вычисляются при загрузке файла или по кнопке «Пересчитать рекомендации». Ползунок, метод и разрешение не запускают анализ повторно и не меняют метки. Готовая рекомендация не перезаписывает ручной выбор во время анализа. После изменения кодировщика, скорости, звука или порога прежние метки сохраняются; их применение блокируется до явного пересчёта или возврата прежних настроек.
- Исходные фрагменты и кадры декодируются один раз и используются совместно анализом и превью. Новое превью кодируется из этих фрагментов; результаты последних 16 сочетаний параметров хранятся в памяти сеанса как ссылки на временные файлы. Возврат к просмотренному качеству не запускает FFmpeg. Звук учитывается в оценке размера отдельно, без повторного кодирования кадров.
- При перетаскивании ползунка меняются подпись и настройки; обработка запускается после отпускания. Прежние кадры остаются видны с подписью «Обновляется…» до получения нового результата. Сравнение временно недоступно, чтобы не показывать старые кадры как новый результат. Временные файлы удаляются при закрытии приложения.
- Ход расчёта виден рядом со шкалой. Готовые метки появляются по мере анализа каждого профиля; кнопка пересчёта остаётся доступна при отмене и ошибке. Рекомендации вычисляются для всех методов; чекбокс во вкладке по умолчанию управляет автоматическим применением выбранного профиля.
- Начальная обработка — NVIDIA GPU, скорость — «Максимальная скорость»: NVENC p1, без lookahead и spatial AQ. Сохранённый пользователем другой выбор восстанавливается.
- Начальный метод — «Авто: качество + разрешение»; сравнение — «Шторка». Масштаб и режим сравнения сохраняются.
- Слева меньший файл и ниже качество; справа выше качество и больше файл. Значение 85/100 — положение на шкале, а не процент качества.
- В режиме «Авто» сначала меняется качество на разрешении выбранного профиля; левее отметки 60 также уменьшается разрешение.
- Режим обработки «Авто» использует проверенный NVIDIA NVENC для H.264 / HEVC, иначе CPU. CUDA ускоряет декодирование поддерживаемых форматов; операции масштабирования, анализа качества и звука могут использовать CPU.
- Во время кодирования подпись показывает реальный кодировщик (`h264_nvenc` / `hevc_nvenc` или CPU). Для оценки загрузки NVENC смотрите отдельный график Video Encode. MPEG-4 в AVI декодируется на CPU; видеокодирование при выборе NVIDIA выполняется NVENC.
- Превью кодируется на исходном или выбранном разрешении с теми же настройками, что и итоговый файл.
- Целевой размер и битрейт приблизительные: используется однопроходное кодирование VBR. Точный размер не гарантируется.
- Обрабатываются SDR-видео, первая видеодорожка и первая аудиодорожка. HDR отклоняется с объяснением, чтобы избежать неявного изменения цвета. Субтитры и дополнительные дорожки в результат не переносятся.

## Рекомендация

Три фрагмента по три секунды берутся около 18%, 48% и 82% длительности. Сравниваются кандидаты CQ/CRF 12, 14, …, 28. Во всех профилях нужны VMAF в среднем не ниже порога, минимум по фрагментам не ниже порога минус один балл и прогноз уменьшения размера минимум на 3%. По умолчанию основной порог 95; его можно повысить во вкладке «По умолчанию».

- **Максимум качества:** исходное разрешение, первый подходящий — наиболее качественный из проверенных — кандидат.
- **Ваш экран:** видео вписывается в физическое разрешение текущего экрана, с учётом масштаба Windows. На этом разрешении выбирается наименьший файл из подходящих кандидатов.
- **Телефон:** ориентир 1280×720 для горизонтального видео, 720×1280 для вертикального. Порог на два балла ниже основного (по умолчанию 93); выбирается наименьший подходящий файл. Модель телефона не определяется.

Исходник никогда не увеличивается. При маленьком исходном разрешении профили могут иметь одинаковое разрешение и отличаться качеством. VMAF сравнивает изображения в одинаковом размере просмотра. Разница менее двух единиц CQ/CRF не исследуется. Результат кешируется для файла, параметров, профилей и разрешения экрана. Выбранный профиль запоминается; при ручном движении ползунка сохраняется его ограничение разрешения. После переноса окна на другой монитор для обновления рекомендаций можно заново открыть видео.

Это оценка по фрагментам, не гарантия качества каждой сцены. VMAF не является процентом сохранённого качества. Если условия не выполнены, приложение не выдаёт ложную рекомендацию. Финальный размер может отличаться от прогноза из-за сложности других сцен. Аппаратное и программное кодирование при одинаковом числовом параметре качества дают разные размеры и визуальное качество.

## Исходники и сборка

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run_app.py
.\build.ps1 -Python .venv\Scripts\python.exe
```

Для запуска исходников и сборки нужны `ffmpeg` и `ffprobe` в PATH; FFmpeg должен поддерживать `libvmaf`. Сборка включает найденные бинарники внутрь EXE. Версия, использованная здесь: FFmpeg 8.0.1 full build.

Документация: [NVIDIA: FFmpeg и NVENC](https://docs.nvidia.com/video-technologies/video-codec-sdk/13.0/ffmpeg-with-nvidia-gpu/index.html), [FFmpeg: libvmaf](https://www.ffmpeg.org/ffmpeg-filters.html#libvmaf).

FFmpeg распространяется под лицензиями LGPL/GPL в зависимости от сборки; использованная full build содержит GPL-компоненты. При дальнейшей передаче EXE соблюдайте условия этой сборки: [сборки Gyan и сведения об исходниках](https://www.gyan.dev/ffmpeg/builds/), [FFmpeg legal](https://ffmpeg.org/legal.html). PySide6 распространяется по лицензиям LGPLv3/GPLv3 или коммерческой лицензии Qt.
